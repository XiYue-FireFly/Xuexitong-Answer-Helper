# Android v1.4.1 — 悬浮底栏与抬升镜片

- 七个工具 Tab 改为悬浮胶囊，网页延伸到底部；横屏限制栏宽，窄屏保留横向滚动。
- 玻璃按底栏真实位置持续读取源网页，修正取样拉伸、上下颠倒和位置偏移。边缘折射、色散与高光随内容及手势变化，不重复采入工具界面。
- 长按时选中镜片抬起，图标和文字在镜片内共同放大并产生边缘折射；拖动时跟手拉伸、刹停回弹，跨 Tab 提供系统触觉反馈，松手吸附到目标后再落下。底栏保持固定，镜片横向不越界。
- 镜片宽度限定为一个按钮，避免覆盖相邻选项；轻点时从当前位置快速平滑滑向目标，长按才启用完整抬升效果。减少动画期间取样与重复布局，修复掉帧后动画被拉长的问题。
- 降低玻璃雾度和底色，保留网页纹理与水滴边缘；修复长网页下滑后仍采到旧内容的位置偏移。
- 同一 Tab 点击展开、再次点击收起；面板外点击只收起并拦住本次手势。面板关闭时，悬浮栏左右及底部留白可操作网页。
- 保留工具草稿、灰化颗粒收起、明暗主题、减少动态效果及 GPU 失效回退。键盘打开时为原生输入保留可用空间，收起后恢复完整网页视口。

版本 `1.4.1`，versionCode `6`。安装包为 Android Debug 签名，可覆盖同签名测试包；最低安装要求仍为 API 24。本轮验证范围为 Android 15、16，Android 17 按要求跳过。

安装包：`Xuexitong-Answer-Helper-android-v1.4.1.apk`。具体测试结果见 [验证记录](https://github.com/XiYue-FireFly/Xuexitong-Answer-Helper/blob/android-v1.4.1/docs/qa/android-browser/floating-glass-v141-verification.md)。

折射使用受限尺寸的源网页采样，后台停止；部分硬件视频或 WebGL 内容可能无法进入软件采样纹理。

# Windows v1.5.1

修复暗色模式下工具 Tab 展开页文字不清晰的问题，尤其是后方为白色网页时。

- 加深暗色面板底色，避免后方未经模糊的网页文字直接穿透，同时保留实时玻璃背景色彩。
- 提亮标题、正文、提示、输入占位文字、筛选按钮和状态文字，调整主操作按钮的底色与白字对比度。
- 新增白色网页背景下的六类文字像素对比度检查，均达到普通文字 4.5:1 要求。
- 保留浮动底栏折射、平滑点按、长按拖动、面板切换动画和草稿保留。

下载 `Xuexitong-Answer-Helper-v1.5.1-win-x64-setup.exe`。关闭应用后，使用原 Windows 账号覆盖安装；请勿先卸载旧版，以保留登录状态、配置和题库。安装包校验值见 `SHA256SUMS.txt`。

本次仅更新 Windows 版本。详见 [验证记录](https://github.com/XiYue-FireFly/Xuexitong-Answer-Helper/blob/v1.5.1/docs/qa/windows-glass/v1.5.1/verification.md)。

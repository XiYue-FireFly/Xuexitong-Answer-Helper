# Android v1.4.0 — 实时玻璃与系统任务进度

- 底栏折射与展开面板背景持续跟随网页变化；采样只读取源网页，避免把玻璃和工具文字反复采入。
- 统一七个工具页的卡片、按钮、输入框和选项材质。长按镜片在最终拉伸后仍限制在底栏内，亮暗主题避免重复绘制选中玻璃。
- 保留同一 Tab 再次点击收起、外部点击收起并消费整个手势、滑动选中、颗粒消散和网页完整视口。
- 移除应用悬浮条及悬浮窗权限。Android 16–17 使用系统实时进度样式，Android 15 使用持续进度通知；卡片与状态栏胶囊由系统决定。
- 新增可选媒体卡片兼容模式：设置 → 真实页面能力 → 后台答题状态 → 开启媒体卡片。以真实题数映射系统音乐进度条，暂停/继续控制可暂停的自动答题任务；不播放声音、不获取音频焦点，不能拖动改变题目进度，任务结束时释放会话。

版本 `1.4.0`，versionCode `5`。安装包使用 Android Debug 签名，可覆盖同签名测试包。已在 Android 15、16 模拟器验证，Android 17 按用户要求跳过验证；保留现有最低 API 24 安装要求。

安装包：`Xuexitong-Answer-Helper-android-v1.4.0.apk`。

媒体模式可能占用音乐控制区域。各品牌是否上岛、卡片展开方式和高光动画由系统控制；未开通厂商准入权限，不承诺所有机型自动上岛。具体测试范围见 [验证记录](https://github.com/XiYue-FireFly/Xuexitong-Answer-Helper/blob/6370b8951a68a611f5bb5ff364874147890d4414/docs/qa/android-browser/live-glass-v140-verification.md)。

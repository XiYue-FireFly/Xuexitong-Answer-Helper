# Android v1.0.0 — 多标签浏览器、图文发送与玻璃工具栏

首个 Android Release，发布日期为 2026-10-25。

## 更新内容

- 原生浏览器适配手机横竖屏，工具面板向上覆盖网页，展开前后浏览器视口保持一致。
- 新增独立浏览器标签页；网页新窗口保留原题页面，标签各自拥有历史，回填时校验并切回原题标签。
- 修复 DeepSeek 手机输入区存在图片删除按钮时漏识别外层发送箭头的问题，支持长提示词与多张图片，检查上传完成及本次发送回执。
- 缺失或无效答案最多补发三轮，仍无有效答案时跳过并继续后续内容，已获得的有效答案照常填回。
- 系统返回键先关闭展开的工具，再返回当前网页历史；修复系统字号变化重建 Activity、丢失标签和草稿的问题。
- 更新浮动玻璃 Tab、功能图标、蓝色书本启动图标及 Android 自适应/单色图标。

下载 `Xuexitong-Answer-Helper-android-v1.0.0.apk` 并在安卓手机上安装。当前发布的是已验证的 **debug 签名 APK**，可覆盖同签名测试包。Android 最低系统要求为 Android 7.0 / API 24，建议使用较新的 Android System WebView。

## 验证范围

- 21 个测试文件、387 项单元测试通过；TypeScript、Vite、Kotlin、APK 构建和 Android Lint 通过。
- Android 10 / API 29 与 Android 15 / API 35 模拟器，WebView 124.0.6367.219。
- 验证横竖屏、独立标签与系统返回、原生键盘 Enter、长提示词加三图发送、完整本地自动答题流程、两层跨域 iframe 抓题回填和子页跳转保护。
- 验证 320 CSS 像素窄屏、明暗主题及显示密度 540/字号 1.3 下的七个工具切换与标签保留。
- 联网只读检查学习通的手机登录重定向和验证码登录入口，没有提交登录或请求短信。

用户取消了本轮新增的密码输入适配。真实学习通账号后的作业/考试，以及真实 AI 登录会话未验证；模拟器自动答题使用本地夹具，不提交作业或考试。

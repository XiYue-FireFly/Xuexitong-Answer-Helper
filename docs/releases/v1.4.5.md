# Release v1.4.5

## 网页 AI 发送修复

- 修复 DeepSeek 图片上传后一直停在“发送提示词”的问题。识别图片附件区域和文件名，兼容首次上传时才出现的附件容器。
- 上传进度按真实可见状态判断，忽略已透明隐藏的上传动画；实际上传期间继续等待，避免提前点击发送。
- 兼容无文字的发送、停止图标与禁用按钮，避免误点停止生成。
- 输入框在发送后重建时，使用本批实际请求编号及全部附件文件名确认消息已发出，减少重复发送或长期等待。

## 题目上下文与图片

- 按材料组整理共享材料、相邻题干和已有作答参考，明确来源，减少跨大题混用上下文。
- 当前页已抓取题目会重新作答，原有填写仅供参考，不直接视为本轮答案。
- 支持读取题干、选项与材料中的真实图片并以映射文件名附加到提示词；可见图片不再仅因 aria-hidden 标记被漏抓。
- 图片读取沿用原页面登录会话，限制超时、文件大小和跳转范围；读取失败时显示处理状态。
- 修复题库答案正文包含 b/s 等字符时误匹配选项字母的问题。
- 修复单输入框的长答案被分号、编号或说明文字截断，保留问答正文和段落。
- 增强整页混合题型提取，排除富文本工具栏伪题、字号输入和图标，减少错误题干入库。

## 多页面任务与发布检查

- 每个题目页维护独立控制器、进度、配置和重试位置，切换标签或收起侧栏后继续执行。
- 页面回包校验任务、操作、标签与文档身份；同一 AI 网站的发送和收集按序执行，降低串答风险。
- 运行期间保留原题页和 AI 页面资源，停止、取消和迟到回包按任务处理。
- Windows 打包脚本在构建或包内验证失败时立即中止；GitHub Release 工作流增加自动化测试步骤。

## 升级与使用说明

下载 Xuexitong-Answer-Helper-v1.4.5-win-x64-setup.exe，关闭应用后使用原 Windows 账号覆盖安装，不要先卸载旧版。沿用既有登录数据、题库与配置的备份恢复机制；正式卸载仍会清理本机数据。

应用不自动提交作业或考试结果。AI 网站的登录、验证、上传和输出限制仍需按网页提示处理；AI 内容请自行核对。

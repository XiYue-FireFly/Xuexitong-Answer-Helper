# 安卓折射底栏与后台任务状态

## 行为

- 七个工具保留点击切换、同 Tab 再次点击收起、长按拖动和窄屏滚动。宽屏可直接滑动选择，窄屏先长按再拖动选择，避免与滚动冲突。
- 镜片按压抬升，图标随镜片放大，位置按弹簧连续跟随；速度影响拉伸，边界使用有限弹性位移，松手惯性最多多移一个工具。布局尺寸不随视觉变形改变。
- Android 11 起使用 WebGL 1 和有尺寸限制的浏览器底部窗口采样作为折射纹理，异步 PixelCopy 避免同步 WebView.draw 阻塞绘制线程。Android 7–10 保留 CSS 玻璃和弹簧交互，不在双 WebView 上叠加 WebGL，避开旧硬件合成器停滞。导航、尺寸变化和按压时更新快照，不逐帧截取。停止移动时停止请求动画帧；隐藏时取消动画和拖动。
- GPU 丢失时保留 CSS 材质和交互。所有截图仅短暂存在内存，释放纹理、缓冲区、着色器、位图及监听器。

## 后台执行

- 订阅网页多任务和 API 任务状态，以实际填入数或实际解答数统计进度，跳过题单独计数；已结束的旧任务不计入当前总进度。
- 只在用户启动任务且应用处于前台时启动前台服务；服务运行后允许更新后台进度。无开机启动、无自动恢复，进程重建不会误显示正在答题。
- 使用 `specialUse` 前台服务声明有限答题任务及可见进度，任务期间维持有超时的部分唤醒锁，结束、关闭或心跳中断时释放。
- Android 13 起首次任务请求通知权限，拒绝后不反复弹出。顶部胶囊独立由用户开启悬浮窗权限，不通过媒体、电话等无关类型伪装状态。
- Android 16 请求系统实时通知提升；实际支持情况查询系统。其他版本和不支持提升的设备使用普通持续进度通知。
- 顶部胶囊仅在任务运行、应用后台且权限可用时出现；不抢输入焦点。遵循系统安全显示区域，横竖屏重新布局，结束或权限关闭时移除。
- 状态只包含通用步骤及计数，不包含网页标题、题干、账号、答案或提示词。

## 验收

单元测试覆盖弹簧停止、反向移动、惯性边界、多任务聚合和状态脱敏。模拟器使用实际 ADB 触摸验证底栏和 GPU 输出，使用本地网页夹具运行完整自动答题并切到桌面，确认后台填回、进度通知、顶部胶囊、任务返回入口以及服务结束。

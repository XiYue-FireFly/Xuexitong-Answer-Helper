# Android v1.3.0 — 折射玻璃底栏与后台答题状态

- 底栏增加 GPU 折射、边缘色散、镜片抬升和图标放大；滑动使用弹簧跟随、速度拉伸、边缘回弹和松手惯性。长按拖动及同一 Tab 再次点击收起保留，窄屏短划用于滚动。
- GPU 不可用时保留 CSS 玻璃材质，减少动态效果时直接移动到目标；切换工具和收起仍使用原有颗粒消散。
- Android 11 起启用 GPU 折射并通过异步窗口采样提供纹理；Android 7–10 使用 CSS 玻璃，保留镜片抬升、图标放大和弹簧交互，避免旧系统双 WebView 与 WebGL 叠加时的渲染停滞。
- 用户启动答题后通过前台服务展示步骤和实际完成题数，切到其他应用后继续处理。任务结束时释放服务、唤醒锁和顶部胶囊；关闭应用后不自动恢复任务。
- 新增“设置 → 真实页面能力 → 后台答题状态”，提供通知权限、顶部状态胶囊和后台电池设置入口。通知及胶囊仅显示通用步骤和计数，不展示题目或提示词正文。
- 顶部状态胶囊需用户开启悬浮窗权限；点击通知或胶囊返回答题工具。Android 16 向系统请求实时更新，是否提升为状态栏胶囊及显示形态由系统决定，其他版本使用持续进度通知。

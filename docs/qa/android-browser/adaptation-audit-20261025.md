# 图文发送与安卓适配验收（2026-10-25）

本轮修复 DeepSeek 手机输入区在长提示词和三张图片已就绪后无法发送的问题，更新玻璃工具 Tab 与启动图标，并补测 Android 系统返回、窄屏、大字体和跨域题目页面。用户已取消新增的密码输入适配；本轮没有修改密码框或新增密码专用处理。保留上一轮已有的本地登录回归测试。

## 修复与验证依据

### 图文提示词发送

旧查找逻辑遇到输入框附近任意按钮就结束祖先遍历。手机布局中的图片删除按钮导致它过早选定输入区边界，漏掉外层页脚的发送箭头，随后回退 Enter；移动端 Enter 可能仅插入换行。

现在以表单、明确发送控件或 DeepSeek 圆形主按钮寻找共同输入区，兼容原生 button 和 role=button，并将发送候选限定在该输入区内。保留上传完成检查、生成中停止控件识别和发送回执确认。状态不确定时不会盲目重复提交。

两个新增单元测试先失败、修复后通过，覆盖三图删除按钮包围输入框，以及输入区外无关发送按钮。安卓端到端夹具使用三张 PNG、重复 1000 次的中文提示词、外层页脚箭头和只会换行的 Enter；横竖屏均验证只发送一次、三图完整、当前 requestId 回执正确、没有误删附件。

### 系统返回与配置变化

已在旧行为上复现：原生浏览器有上一页时，Android 系统 Back 仍退出应用。新增生命周期绑定的返回处理，依次关闭弹窗、地址编辑或展开工具，再返回当前浏览器历史；没有历史时将任务放到后台。模拟器使用真实 Android Back 验证历史返回和面板收起，收起工具时原题页面不跳转。

大字体补测还复现了 font_scale 改变触发 Activity 重建、原生 WebView/CDP 被关闭的问题。Activity 现在处理 fontScale 配置变化。相同测试在切换显示密度及 1.3 倍字号后继续使用原有浏览器页面和标签，通过后续工具切换与视口检查。

### 玻璃工具 Tab 与图标

底部工具导航采用浮动圆角玻璃胶囊、渐变反光、内边框、选中高亮和按压反馈。七个功能使用独立图标并提供可访问名称、面板关联和展开状态。窄屏允许横向滚动，右侧收起按钮保持可见。浏览器底部预留包含浮动 Tab 下方空隙，面板展开不改变浏览器视口。

蓝色书本与星光图标提供五档密度 PNG、圆形版本、API 26 adaptive icon 和单色主题层。Android Lint 的图标单色层及 Manifest 顺序警告已修正。

## 联网检查范围

在 Android WebView 中访问学习通公开登录 URL，确认安卓会跳转到 `/mlogin`。当前手机页仍提供 `#phone` 和 `#pwd`，手机登录脚本版本为 `20261016a`，与桌面公开登录脚本不同。打开验证码登录入口，确认 `#phone` 为 tel、`#vercode` 为 tel，页面标题为“验证码登录”。没有填写真实账号、获取短信或提交登录。

公开页面记录：`public-learning-login.json`、`public-learning-sms.json`、`public-learning-login.png`。DeepSeek 未登录公开页面会跳到 `/sign_in`；公开脚本研究结合截图结构用于定位发送区，不能据此声称真实登录会话已经验证。

真实学习通账号后的作业、考试以及真实 AI 服务发送尚未验证。Android 24–28、其他 WebView 版本和各厂商系统未逐机测试；本报告不保证所有后续网站变化都能自动适配。

## 更新内容

- 设置页新增从当前 AI 服务的 `/models` 接口拉取模型列表的能力，支持选择已拉取模型，同时保留预设模型和手动填写模型名称。
- 将右侧功能入口改为可收起的竖向图标栏，点击图标即可展开相应面板。
- 标题栏增加可拖动区域，窗口最小化、最大化和关闭按钮保持独立可点击。
- 移除设置页“赞赏支持”入口及相关二维码资源。

## 修复说明

- 修复学习通网页登录状态在关闭应用后偶发丢失的问题：WebView 使用固定持久化分区，并在页面加载稳定后及应用退出前主动刷新 Cookie、Local Storage 和 IndexedDB 等存储数据。
- 修复右侧面板的高度约束问题，恢复设置、自动化、章节学习等长内容的鼠标滚轮滚动。
- 修复主进程异常日志在标准错误输出管道关闭时可能再次触发 `EPIPE` 的问题，避免错误记录流程放大原始异常。
- 模型列表接口发生跨域重定向时不再携带 API Key 请求头，避免认证信息被转发到非原始服务域名。

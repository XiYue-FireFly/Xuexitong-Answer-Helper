# Windows v1.5.0

## 液态玻璃与操作

- 七个工具 Tab 悬浮在网页上，实时显示、折射当前视口内容。长页面下滑后继续更新，避免残留滚动前画面。
- 点按镜片快速平滑移动到目标按钮；镜片限制在单按钮范围。长按抬起后可以拖动，松手吸附到目标，拖出栏外仍能完成选择。
- 工具面板覆盖网页，不再挤占网页宽度；再次点击同一个按钮即可收起。点击面板外部收起时吞掉本次完整手势，防止误触网页。
- 七个工具页统一玻璃卡片、选项、按钮和输入框。切换与关闭带有渐隐颗粒效果，已打开的编辑器保留草稿和运行状态。
- 适配深浅主题、明亮网页文字对比度、窗口缩放、减少动态效果；图形上下文丢失时使用基础玻璃并自动恢复。
- 窗口最小化时停止网页取样，恢复后继续更新。取样只读取本应用当前网页，不采集其他窗口。

## 安装与校验

下载 `Xuexitong-Answer-Helper-v1.5.0-win-x64-setup.exe`。关闭应用后，使用原 Windows 账号覆盖安装，不要先卸载旧版；沿用既有登录状态、配置和题库的备份恢复机制。

`SHA256SUMS.txt` 提供安装包 SHA256。Windows 与 Android 安装包分别存放，构建互不覆盖。本次仅发布 Windows 版本。

验证范围和结果见 [Windows 验证记录](../qa/windows-glass/v1.5.0/verification.md)。

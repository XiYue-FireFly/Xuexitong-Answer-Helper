# 安卓折射底栏与后台任务状态

## 行为

- 七个工具保留点击切换、同 Tab 再次点击收起、长按拖动和窄屏滚动。宽屏可直接滑动选择，窄屏先长按再拖动选择，避免与滚动冲突。
- 镜片按压抬升，图标随镜片放大，位置按弹簧连续跟随；速度影响拉伸，最终变形后的镜片限制在底栏内侧 4px，松手惯性最多多移一个工具。布局尺寸不随视觉变形改变。
- Android 11 起使用 WebGL 1 和有尺寸限制的浏览器底部采样作为折射纹理。只绘制源 WebView，避免采入工具层造成反馈；JPEG 压缩在线程池执行。Android 7–10 保留 CSS 玻璃和弹簧交互，不在双 WebView 上叠加 WebGL，避开旧硬件合成器停滞。底栏持续串行采样（普通模式间隔 65ms，减少动画时 160ms，另加采样与解码耗时），展开工具的背景间隔 220ms。每个消费者至多一个请求在途；后台停止采样和动画，恢复前台后重新采样。
- GPU 丢失时保留 CSS 材质和交互。所有截图仅短暂存在内存，释放纹理、缓冲区、着色器、位图及监听器。

## 后台执行

- 订阅网页多任务和 API 任务状态，以实际填入数或实际解答数统计进度，跳过题单独计数；已结束的旧任务不计入当前总进度。
- 只在用户启动任务且应用处于前台时启动前台服务；服务运行后允许更新后台进度。无开机启动、无自动恢复，进程重建不会误显示正在答题。
- 使用 `specialUse` 前台服务声明有限答题任务及可见进度，任务期间维持有超时的部分唤醒锁，结束、关闭或心跳中断时释放。
- Android 13 起首次任务请求通知权限，拒绝后不反复弹出。不再申请悬浮窗权限或创建应用悬浮条。
- Android 16–17 使用系统 ProgressStyle 和实时通知提升请求；实际支持情况查询系统，设置页提供原生设置入口。Android 15 使用持续进度通知。
- 状态栏胶囊、展开卡片、进度动效与外观由系统控制；不支持时保留通知。未获得厂商准入，不写入未经验证的厂商私有参数。
- 用户可主动开启媒体卡片兼容模式：MediaSession 与 MediaStyle 共用任务通知，以 completed/total 映射进度，速度固定为零，不播放音频、不申请音频焦点、不支持拖动或跳曲。暂停/继续只开放给可暂停的真实任务，完成、切回原生模式或服务销毁时释放会话。无任务时不创建会话。此模式可能占用音乐卡片区域，是否上岛由设备系统决定。
- 状态只包含通用步骤及计数，不包含网页标题、题干、账号、答案或提示词。

## 验收

单元测试覆盖弹簧停止、反向移动、惯性边界、多任务聚合和状态脱敏。模拟器使用实际 ADB 触摸验证底栏和 GPU 输出，使用本地网页夹具运行完整自动答题并切到桌面，确认后台填回、系统进度通知、可选媒体卡片暂停/恢复、任务返回入口以及服务和媒体会话结束。本轮目标 Android 15–17；厂商系统上岛需要真机核验，不能用 AOSP 模拟器替代。

# 作业全题提取、题干对应与长答案填入修复

日期：2026-10-20。版本仍为 1.4.4；未提交、推送、打包安装或发布。

## 问题与根因

用户截图中，页面简答题只写到首个分号之前，题库题干却显示“段落格式字体字号点击上传x”。两项问题均以夹具重现，而非根据是否曾作答来推测。

1. 问答与单输入框答案共用多空解析器，在写入之前按分号、编号、`##` 等切分，且清洗器还会删除“分析/说明：”后的正文。只有第一个切分值写入单个编辑器，随后校验的也是这个已截断值，因而错误报告成功。
2. UEditor 内部通用 `.question/.title/.content` 被当成真实题目候选。嵌套候选优先使外层真题被移除，于是工具栏文字被送给 AI 并入库；工具栏图片和字号输入也可能被误认为题图或旧答案。
3. 当前自动控制器已经使用本次抓取的全部题目，不依据已有填写过滤；本次不再修改该生产逻辑，而是对其实际发送 JSON、入库、填回增加整页混合题型回归。

## 使用与限制

完全退出当前 App 并从项目目录运行 `npm run electron` 后，重新执行该作业的自动答题，才能加载本轮 preload。没有主动关闭用户原 App，也没有改动用户已有登录或本地题库数据。

本轮修复新提取、新入库及新填入的数据。历史中已经错误保存的工具栏条目，无法仅凭工具栏文字安全恢复原题；不会据此批量删除或猜测修改现有题库。重新运行会按真实题干入库，旧误条目可在题库删除。

多空填空仍沿用原有缺少答案时的兼容策略，本次不调整；单答案正文不再被分号、编号、`##` 等截断。当前线上作业的实际 DOM 仍待重启后复测，本地夹具不代表所有站点布局都已经实测。

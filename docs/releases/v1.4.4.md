# Release v1.4.4

## 网页 AI 答题修复

- 提示词逐题包含真实题型、中文题型名和作答规则。单选题只接受唯一合法答案；AI 返回多个选项时自动补发该题，真实多选题仍支持多个正确选项。
- 自动模式先将已取得的有效答案录入题库，仅重新发送缺失或无效题目，收齐全部可发送题后统一填回原页面，无需逐批人工确认。手动模式保留原确认步骤。
- 同一道题最多自动补发三轮，仍未取得答案时保留已录入内容并展开重试入口；点击“重试失败步骤”继续处理未完成题。
- 已结束且截断的回答可保留其中完整、合法的答案，继续补齐剩余题目；不会将仍在生成或旧消息重绘当作新回答而重复发送。
- 修复单选题内容相似时多个选项同时高亮、选中圆圈放大及正文被遮挡；原生单选框、隐藏答案值和选项标记按同一目标同步。

## 题库与窗口

- 题库保存抓取到的原始题型，导入导出保留题型；旧题库中的“对/错”成对选项兼容识别为判断题。
- 判断题兼容 `true/false` 布尔答案，显示“正确/错误”，并按含义高亮对应选项。
- 自动运行开始时收起侧栏，暂停、失败、长等待提醒或部分完成时展开；修复跨浏览器区域拖动时无法向外拉宽的问题。
- 应用启动时自动最大化，占满系统可用屏幕，保留任务栏及窗口控制按钮。

## 升级说明

下载 `Xuexitong-Answer-Helper-v1.4.4-win-x64-setup.exe`，关闭应用后使用原 Windows 账号覆盖安装，不要先卸载旧版。沿用现有登录数据、题库与配置的备份恢复机制；正式卸载仍会清理本机数据。

每批完整提示词上限仍为 **300000 字符**，不限制题数；单题连同模板超限时跳过该题。自动答题处理当前页面，不自动翻页或提交作业、考试。AI 网站自身的登录、验证、上传和输出限制仍需按网页提示处理。

## 更新内容

- 新增网页 AI 答题入口，可选择 DeepSeek、豆包、千问，并保留原有 API AI 方式。
- 网页 AI 改为独立按钮操作：生成提示词、打开网站、发送提示词、提取答案、确认入库和确认填入。打开网页后，悬浮操作栏保留发送和提取按钮。
- 单批提示词支持最多 50 道题，应用侧长度上限从 3 万提高到 30 万字符；超过 50 题可在完成本批后手动生成下一批，剩余题目不会丢弃。
- 支持在系统默认浏览器使用网页 AI：复制提示词后自行发送，将完整回答粘贴到应用中预览并确认入库。
- 升级工作台、本地题库和浏览器区域的界面，加入卡片微动效、任务流光进度、右侧竖向导航和可拖动宽度的工作区；启动默认显示本地题库。
- 调整浅色模式的文字、背景、题型标记和按钮对比度，移除本地题库界面的云端题库入口。

## 修复说明

- 修复网页 AI 填入提示词后因发送按钮暂未启用或无法识别而立即弹窗的问题：等待按钮就绪，必要时尝试真实回车按键，并检查发送结果；发送异常时保留网页供手动处理。
- 发送请求的确认结果不明确时不自动重复提交；提取、入库和填入均由用户点击相应按钮触发。
- 网页 AI 回答通过批次请求 ID 和题目 ID 对应原题，选择题同时校验选项字母与正文，避免乱序回答、旧批次回答或字母与选项正文不一致时误填。
- 保留取消和任务互斥保护，填入前重新核对原题页面、题目和选项，并使用当前页面的定位信息。
- 调整网页登录信息的保存方式：主动刷新 Cookie 与网页存储，并将会话 Cookie 持久化保存，减少应用关闭后本地登录信息丢失的情况。网站服务端使登录失效时仍需重新登录。
- 修复标题栏主题切换与窗口控制区的交互、颜色同步，并完善侧栏宽度调整和内容滚动布局。

## 使用与验证说明

- 应用内网站首次使用需要用户自行登录；系统浏览器模式由用户自行发送提示词并粘贴回答。
- 50 题与 30 万字符是应用侧上限，网站自身的输入长度、生成长度和账号限制仍然适用。回答被截断时，请减少所选题目后重新生成。
- 24 项离线校验测试通过，覆盖答案映射、发送状态、50 题批次、剩余题目及提示词长度边界。前端构建通过；当前环境尚未完成三个网站的真实在线流程验证。

# Android 液态玻璃工具栏

用户已批准：七个工具 Tab、透光玻璃、连续滑动的选中胶囊、轻回弹面板；点击面板外空白只收起面板，消费整个手势。

## 补充要求（2026-11-17）

- 同一个 Tab 点一次展开，再点一次收起，删除独立展开/收起按钮。点击其他 Tab 切换并保持展开。
- 长按 Tab 后拖动，玻璃胶囊持续跟随手指、随移动拉伸，松手吸附目标；窄屏边缘自动滚动。短划保留底栏滚动。
- 实现真实控件像素的灰化、顺序消散和飘移。工具页切换及用户收起时运行，任务自动返回网页时直接关闭，减少动态效果时跳过。
- 统一 App 自有的地址栏、标签页、七个工具页卡片、按钮、输入框、选择器和弹窗材质。网页由对应网站控制，不注入玻璃样式。
- 截图仅短暂保存在内存，用完释放，不写入用户输入或网页图片到磁盘；快速重入、旋转、后台和任务启动取消过期动画。

浮动胶囊、边缘高光、蓝色选中态及弹性动画使用 React/CSS/Kotlin 实现，工具页颗粒消散使用 Canvas 渲染。

## 视觉与状态

- 七个工具、浏览器标签页及工具内容保持挂载。面板开闭不改变原生网页尺寸。
- 底栏增加独立的选中玻璃胶囊，位置和宽度随选中按钮及窗口尺寸变化；七 Tab 在窄屏横向滚动，点击当前 Tab 可展开或收起。
- 面板采用网页模糊快照、独立明暗 tint、薄高光边缘。快照在打开和视口变化时更新，不逐帧抓取网页。
- 打开采用轻回弹，关闭稍快。CSS transition 支持中途反向；减少动态效果偏好下直接切换。
- 保留最小 44px 触摸目标（横屏键盘极小视口沿用紧凑模式）。

## 触摸契约

- NativeWebView.setLayout 同步 panelOpen（包括关闭动画期间的拦截状态）。BrowserOverlayLayout 仅在工具完全关闭且无 dialog 时转发网页手势。
- 每次 ACTION_DOWN 决定整段手势的接收层；ACTION_UP/CANCEL 之前不因面板状态改变而换层。
- React 的面板外关闭按钮位于 header 下方、dock 上方、面板背后；点击关闭，拖动不关闭；打开的 dialog 优先处理输入。
- 面板关闭后再点击同一位置，网页才接收该次手势。关闭动画过程中重复点击继续拦截。

## 验收

使用 API 35 和 API 29 模拟器的 ADB 真实触摸验证首次外侧点击不会到达网页，第二次点击可到达；长按、拖动、快速反向开闭、Tab 连切、输入草稿、旋转、320px 明暗主题及减少动态效果。运行现有自动答题、图文发送、标签页和输入回归，生成本轮 APK 和 QA 记录。

# Release v1.4.2

## 功能调整

- 移除已停用的章节学习入口、专用事件与脚本打包资源，保留答题所需的字体解码和页面答案同步能力。
- 右侧新增“使用教程”，涵盖网页 AI 六步、系统浏览器操作、API 配置、题库录入与常见问题。
- 网页 AI 取消每批 50 题限制，按完整提示词 **300000 字符**整题分批，包含模板、上下文、选项和 JSON 字符。
- 当前批次放不下的完整题目进入下一批；单题连同模板仍超限时跳过本次发送，显示题号与原因，保留原始题目。
- 保留旧草稿的请求 ID；损坏或超长草稿提示重新生成，避免无效发送。

## 界面优化

- 网页 AI 按钮沿用现有玻璃风格，完善主要、辅助、停止与禁用状态，支持深浅主题和键盘焦点。
- 答题进度采用柔和的轨道流光，完成或错误时停止动画，并支持减少动效设置。

## Windows 安装

下载 `Xuexitong-Answer-Helper-v1.4.2-win-x64-setup.exe` 并运行安装。升级安装会保留本机题库、配置和网页登录状态；正式卸载会清理这些应用数据。

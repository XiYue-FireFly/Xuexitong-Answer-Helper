# Release v1.4.3

## 网页 AI 自动答题

- 新增“自动答题”：抓取当前页面可识别的全部题目，生成提示词、自动分批、打开 AI 网站、发送、持续检测回答，校验通过后入库并填回原题页。不自动翻页，不最终提交作业或考试。
- 每批完整提示词上限仍为 **300000 字符**，不限制题数；完整题目进入下一批，单题连模板超限时跳过本次发送，原题保留。
- DeepSeek、豆包、千问按聊天输入框是否可用尝试发送，支持网站提供的游客聊天；网站实际要求登录或验证时，处理后可重试失败步骤。
- 提示词一次性录入，网站转为 TXT 时等待附件上传完成后直接发送。重试复用本批附件，避免重复粘贴；已有其他草稿或旧附件需先处理。
- 自动和手动发送都会持续检测生成结束并提取回答。缺题、低置信度或警告会停下要求核对；手动步骤仍需明确确认入库和填入。
- 失败可从当前批次的失败位置继续；发送状态不确定时先检查网页，避免重复发送。等待较长时间没有完整回答时会提醒查看，同时继续检测。
- 收起右侧栏或切换侧栏页面后，任务继续运行；请保持应用、原题标签和 AI 标签打开。

## 进度与界面

- 答题进度只按实际解答或填入成功数统计，抓题不再混入百分比；保留流动轨道和播放头反馈。
- 答题中显示全页面流星雨，提取成功显示像素猫，全部目标完成后显示礼花并播放提示音。支持静音和系统减少动态效果设置。
- 修复 Web 答题大面板鼠标悬停时大幅变形，保留小尺寸进度浮层。
- 更新右侧“使用教程”，补齐自动与手动流程、TXT 发送、重试、进度反馈和升级说明。

## Windows 升级

下载 `Xuexitong-Answer-Helper-v1.4.3-win-x64-setup.exe`，关闭应用后使用原 Windows 账号直接覆盖安装。安装器在移除旧版前备份本机数据，在首次启动前恢复并校验，以保留登录状态、题库和配置。

不要先卸载旧版，正式卸载仍会清理本机数据。备份或恢复失败时，保留提示中的 `StudyPilotUpgradeBackup` 恢复目录并重新运行安装包；恢复成功前不要启动应用。网站自身使登录失效时仍需重新登录。

## 使用说明

网页布局、上传限制和输出限制由 AI 网站控制。网站更新可能影响自动识别；遇到问题请检查网页提示，使用“重试失败步骤”，或改为手动复制问答。自动填回不会替代答案核对。
